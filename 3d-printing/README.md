# 3D 打印

本目录用于 DuduClock / ESP32-C3 + 2.4 寸 ST7789 屏幕的外壳与装配件。

## 模型格式怎么选

- **3MF**：拓竹 Bambu Studio 的首选交付格式，通常已经包含摆放、支撑和切片参数。
- **STEP / STP**：需要继续修改尺寸或结构时使用，适合 CAD 编辑，不直接作为最终打印格式。
- **STL**：只有 STL 时可以直接导入 Bambu Studio，但它是三角网格，后续改尺寸不方便。
- **OBJ**：仅在模型带有特殊材质/颜色需求时考虑；普通外壳不优先使用。

## 推荐打印顺序

1. 先打印一个 **屏幕开窗和安装孔的尺寸验证件**，不用完整外壳。
2. 尺寸确认后打印前盖。
3. 最后打印后盖和底座，确认 Type-C、按键、传感器和排线都有足够间隙。

## 初始参数

- 材料：先用 PLA/PLA+ 做尺寸验证；最终外壳优先 PETG 或 PLA+。
- 层高：0.16–0.20 mm。
- 外墙：3 层以上。
- 填充：15–25%。
- 屏幕开窗目标：约 `49.5 × 37.2 mm`。
- 屏幕背部沉台：约 `60.8 × 43.2 × 2.8 mm`。
- Type-C 开孔：约 `10.5 × 6.5 mm`，并预留插头外壳空间。
